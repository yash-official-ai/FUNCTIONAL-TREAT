# 📊 Data Analyzer and Transformer Program

A powerful and beginner-friendly Python program that allows users to input, analyze, transform, filter, and sort numerical datasets through an interactive menu-driven interface.

---

## ✨ Features

✅ Input and store numerical data  
✅ Display dataset summary using built-in functions  
✅ Calculate factorial using **recursion**  
✅ Filter data using **lambda functions**  
✅ Sort data in ascending or descending order  
✅ Display dataset statistics using functions with multiple return values  
✅ Interactive and user-friendly menu system

# 📌 Functionalities

## 📥 1. Input Data

Users can enter a 1D array of numbers separated by spaces.

### Example:

```text
56 67 78 98
```

---

## 📊 2. Display Data Summary

Displays:

- Total elements
- Minimum value
- Maximum value
- Sum
- Average

### Example Output:

```text
Data Summary:
- Total elements: 4
- Minimum value: 56
- Maximum value: 98
- Sum of all values: 299
- Average value: 74.75
```

---

## 🔁 3. Calculate Factorial (Recursion)

Uses recursion to calculate factorial values.

### Example:

```text
Factorial of 8 is: 40320
```

---

## 🎯 4. Filter Data by Threshold

Filters values greater than or equal to a given threshold using lambda functions.

### Example:

```text
Filtered data (values >= 67):
67, 78, 98
```

---

## 🔃 5. Sort Data

Supports:

- Ascending Order
- Descending Order

### Example:

```text
Sorted data in Descending order:
98, 78, 67, 56
```

---

## 📈 6. Dataset Statistics

Returns multiple statistical values from a function.

Includes:

- Minimum
- Maximum
- Sum
- Average
